# Teacher Vanessa's Private Class Dashboard

A static, GitHub Pages-compatible dashboard for managing private classes, students, schedules, payments, reports, and settings.

## Features

- Local storage persistence with no backend
- Dashboard summary cards and quick activity feed
- Student directory with add, edit, and delete actions
- Weekly schedule with calendar view and overlap warnings
- Payment tracking with paid/unpaid status changes
- Class records management with filters and quick updates
- Reporting by month for attendance and revenue
- Settings panel that updates the app immediately

## Run locally

Open `index.html` directly in a browser, or serve it with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload the project contents to a GitHub repository and publish through GitHub Pages. The app uses relative paths and static files only.
